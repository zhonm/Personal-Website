# Zhon Mark Manaois - Portfolio

A modern, responsive portfolio website showcasing my skills, experience, and certifications as a Full-Stack Developer and BSIT student.

## ✨ Features

- **Modern Liquid Glass Design** - Inspired by Apple's glassmorphism aesthetic
- **Fully Responsive** - Optimized for all screen sizes (mobile, tablet, desktop)
- **Smooth Animations** - AOS scroll animations and CSS transitions
- **Interactive Elements** - Hover effects, parallax scrolling, and dynamic interactions
- **Accessible** - ARIA labels, keyboard navigation, and semantic HTML
- **Fast Loading** - Optimized assets and lazy loading for images

## 🛠️ Technologies Used

- HTML5 / CSS3
- JavaScript (ES6+)
- Bootstrap 5
- AOS (Animate on Scroll)
- Typed.js
- GLightbox
- Boxicons

## 📁 Project Structure

```
Portfolio/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # Modern glassmorphism styles
├── js/
│   └── main.js         # Interactive functionality
├── img/
│   ├── certificates/   # Certification images
│   ├── logo/           # Skill icons
│   └── portfolio/      # Project screenshots
├── vendor/             # Third-party libraries
└── favicon/            # Favicon files
```

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in a browser or serve via XAMPP/local server
3. Customize content in `index.html` with your information
